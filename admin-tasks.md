## TASK-16 — Додати керовану публікацію програми

| | |
|---|---|
| **Тип** | Task |
| **Пріоритет** | Високий |
| **Роль** | Адмін / Організатор |
| **Компонент** | Backend (статус публікації, права) + Frontend |
| **Залежності** | Пов'язано з BUG-11 |

### Опис
Потрібна кнопка «Опублікувати програму», щоб програма не була доступна всім до рішення організатора.

### Поточний стан
Програма видна користувачам одразу.

### Очікуваний результат
До публікації програма доступна лише організатору та адміну.

### Технічні нотатки
- Поля програми: `status` (`draft` | `published`), `publishedAt`.
- Кнопки «Опублікувати», «Зняти з публікації» та «Оновити опубліковану версію».
- Рекомендовано: під час публікації зберігати знімок, щоб незавершені правки не бачили всі; показувати індикатор «Є неопубліковані зміни».
- Перевірку робити на бекенді: публічний ендпоінт програми повертає «Програма ще не опублікована», якщо `status = draft`.

### Критерії приймання
- [ ] До публікації учасники, тренери та гості бачать повідомлення «Програма ще не опублікована».
- [ ] Після публікації всі бачать актуальну версію.
- [ ] Програму можна зняти з публікації.
- [ ] Обійти приховування через прямий запит до API неможливо.

## TASK-17 — Дозволити організатору реєструвати учасника від будь-якої студії та тренера

| | |
|---|---|
| **Тип** | Task |
| **Пріоритет** | Середній |
| **Роль** | Організатор / Адмін |
| **Компонент** | Frontend (форма заявки) + Backend (права, зв'язки) |
| **Залежності** | Пов'язано з BUG-23 |

### Опис
Організатор має реєструвати учасника, вибираючи будь-яку студію і будь-якого тренера (керівника).

### Поточний стан
Організатор не може вибрати довільну студію й тренера.

### Очікуваний результат
У формі заявки організатор вибирає студію й тренера з усіх наявних (або створює нових).

### Технічні нотатки
- Для ролей організатор (свого конкурсу) і адмін поля «Студія» та «Тренер» — вибір з пошуком по всіх записах плюс «Створити нового».
- Заявка зберігає обрані `studioId` і `trainerId`, а `createdBy` — організатора.
- Така заявка має з'являтися в «Моїх заявках» обраного тренера (див. BUG-23).

### Критерії приймання
- [ ] Організатор може вибрати будь-яку студію й тренера.
- [ ] Заявка створюється з вибраними зв'язками.
- [ ] Заявка видна у вибраного тренера в «Моїх заявках».
- [ ] Інші ролі такої можливості не мають.
