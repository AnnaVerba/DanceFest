## Адмін / Організатор

### 1. Положення фестивалю (PDF)

- [ ] Додати віконце, куди можна завантажити PDF-файл положення фестивалю з усією інформацією.

**Уточнення (Анна):**
- Положення видно **тільки в деталях конкурсу**.
- Завантажують **адмін та організатор**; решта користувачів **скачують** файл собі.
- Файл **один** (нове завантаження замінює попереднє).

### 2. Шаблони номінацій — вікові межі

- [ ] Не дозволяє створити шаблон: вікові межі не редагуються.
- [ ] У шаблоні вік не редагується — дозволити редагування.
- [ ] Дозволити **перетин вікових меж** (межі можуть перетинатися).

### 3. Створення номера / розподіл

- [ ] Прибрати розподіл на цьому кроці — його зручніше робити пізніше.
- [ ] Не додається вік.
- [ ] Тривалість імпровізації вказувати на сторінці таймінгів (а не тут).
- [ ] Прибрати галочку «Імпровізація» — статус імпровізації позначається пізніше.
- [ ] Імпровізацію рахує як соло (встановлено статус «імпровізація», таймінг перераховано), хоча імпровізацію танцюють **кілька людей одночасно**.

### 4. Нумерація номерів

- [ ] Номер присвоюється не логічно: для кожного **групового** номера має бути **унікальний** номерок.

### 5. Таймінги — тривалість групових номерів

- [ ] Тривалість групових номерів **не залежить від ліги**.
- [ ] У таймінгу додати можливість встановити тривалість окремо для **дуетів, тріо, груп** тощо.
- [ ] Для **імпровізації** — щоб кожен організатор міг встановити, напр. **30 сек на учасника**.

### 6. Додавання номінацій

- [ ] Незручно додавати номінації. Зробити за тією ж схемою, що й у шаблонах — **перевикористання з шаблону**.

### 7. Фінанси — вартість для учасника

- [ ] Біля кожного учасника показує **загальну вартість групового**, а не те, що він має заплатити.
- [ ] У фінансах має показуватися **та сама ціна**, яку задали для цієї категорії.
- [ ] Не додає до кожного учасника вартість групового.

### 8. Спецномінації — подвійний рахунок

- [ ] «Корону» з двома виходами рахує двічі (за два виходи 1500 замість 1500 за кожен).
- [ ] **Усі спецномінації** мають оплачуватися **один раз**, незалежно від кількості виходів.

### 9. Групові — вік і склад

- [ ] У групових дати можливість **обрати вік** (зараз, схоже, додає вік усіх учасників).
- [ ] У конструкторі шаблонів номінацій, у розділі «Склад», додати можливість обрати **кількість людей**.

---

## Програма (публічна / технічна)

- [ ] У публічній програмі зробити назву категорії **яскравішою**.
- [ ] Замість «№ номінації» поставити **F**.
- [ ] Додати можливість **скачати технічну та публічну програму** в PDF або іншому форматі *(якщо реально і не важко)*.
- [ ] Додати можливість переміщати в межах відділення не тільки окремий номер, а **цілу номінацію**
      (при 15 учасниках у номінації переносити по одному — дуже довго).
- [ ] Переміщати номінацію повністю так само, як і окремий виступ.
- [ ] Виділяти в програмі кольором або шрифтом виступ **учасника** (для учасника) або виступи **його учнів** (для тренера) — було зручно до оновлення.

---

## Тренер / Учасник

- [ ] Додати можливість **видаляти учасників**.
- [ ] Прибрати можливість додавати **треки до імпровізації** — і учаснику, і тренеру.
- [ ] Треки мають підписуватись **номером учасника**, а не номером заявки.
